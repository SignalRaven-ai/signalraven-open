# signalraven-open

Public integration artifacts for SignalRaven (https://signalraven.ai): LinkedIn buying-intent signals, qualified against your ICP, delivered to the tools your team uses.

- `mcp-registry/server.json`: the official MCP registry entry for the SignalRaven MCP server (https://api.signalraven.ai/mcp).
- `postman/`: the public API as an OpenAPI 3.1 document and a Postman collection.
- `n8n-templates/`: importable n8n workflows that start from a SignalRaven signal.
- `claude-code-plugin/`: a Claude Code plugin bundling the MCP server and two skills.

Docs: https://signalraven.ai/developers · https://signalraven.ai/integrations · support@signalraven.ai
